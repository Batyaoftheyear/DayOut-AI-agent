# Оценка качества DayOut

Измерения: 02–10.11.2026. Текущая конфигурация приложения: Alice AI LLM Flash, Yandex AI Studio, код `2026-11-11-r34`. Модель и версия каждого измерения указаны отдельно; полный повтор всех сценариев на текущей конфигурации не проводился. Код и наборы сценариев имеют SHA-256 в каждом отчёте. Измеряется локальный `web_backend.run_action` с настоящими API — тот же адаптер, что обслуживает интерфейс. Это не нагрузочный тест Streamlit.

## Наборы и критерии

- `eval/cases.json`: 30 живых сценариев / 37 реплик. 20 разработческих и 10 отложенных; к моменту повторных прогонов отложенная часть уже известна, поэтому результат не называется оценкой на новом независимом наборе.
- `eval/completion_cases.json`: 4 составных сценария / 8 реплик. Проверяются цена выбранного места, строгий пеший предел, конкретные занятия и еда, уточнения и смена задачи.
- L01 из `eval/extended_cases.json`: 15 реплик в одном сеансе. Поиск, смена района, изменение и отмена бюджета, погода, маршрут и возврат к ресторанам.
- S01–S04: искусственные отказы без внешних API. Эти проверки не объединяются с живым качеством.

Каждый сценарий начинается с чистой памяти. Реплики внутри него используют общий разговор. Дата посещения зафиксирована в metadata.visit_date каждого отчёта; при повторении выбрать актуальную дату в пределах прогноза. Относительное «завтра» определяется датой запуска в часовом поясе Москвы.

Автоматические проверки: завершение, реальные инструменты и их исходы, запреты на лишние действия, даты, сохранение бюджета, обязательные и запрещённые фрагменты, источники. Исправленная ошибка аргументов остаётся отмеченной: удачный конечный ответ не стирает историю восстановления.

Содержание оценивает отдельный запрос к той же модели по настоящим данным инструментов: соответствие задаче, ограничениям, источникам, честность и выбор инструментов. Локальная память не является доказательством свойств заведения. Оценка моделью может пропустить ошибку; независимой человеческой разметки полного набора нет.

«Все ответы получены» — техническое завершение. «Все критерии пройдены» — успешны все автоматические и модельные проверки. Внешний отказ остаётся неуспехом сквозного сценария. Не начатые из-за ограничителя реплики не считаются успешными.

## Разбор ошибок и практические границы

В длинном диалоге запланировано 15 реплик: получены 13 ответов, 14-я попытка завершилась сетевым таймаутом, 15-я не запускалась. В таблице показаны фактически предпринятые попытки; это не полный успешный разговор из 15 ответов.

Ошибки параметров и ошибки содержания учитываются раздельно. Для найденных точек приложение преобразует короткие метки в полученные от Maps идентификаторы и координаты. Маршруты сопоставляются с кандидатами; уже полученный маршрут в рамках одного хода не запрашивается повторно. Предел времени проверяется в секундах.

Цены не являются обязательным полем выдачи. Отсутствие цены в общем поиске требует отдельного запроса о расходах выбранного места. Отсутствие данных после такого запроса допускает честную неизвестность, но не обещание уложиться в бюджет. Диапазон, средний чек и фактический заказ — разные величины.

Для составного сценария нужны сведения по каждой запрошенной части. Слово «азиатская» у кухни не делает павильоны тематически азиатскими. Подбор в парке должен учитывать его расположение; название парка в запросе не доказывает близость каждого результата. Даже настоящая ссылка не подтверждает любое добавленное описание.

Семантический проверяющий в промежуточной реализации добавлял лишние требования и неверно переносил пожелания между частями задачи. В текущем рабочем цикле такого второго планировщика нет: основная модель выбирает действия, отдельный запрос только сохраняет пользовательские условия. Ошибка сохранения условий не уничтожает уже полученный и проверенный ответ; она отмечается в диагностике.

Сетевые ошибки, квоты, фильтрация и ограничения генерации могут прервать сценарий. Повтор не заменяет исходную неудачную попытку в отчёте. Длинный диалог и сложные сочетания условий нельзя считать безошибочными на основании одного прогона.

## Воспроизведение

```powershell
python eval_runner.py --mode live --cases eval/cases.json --split all --visit-date YYYY-MM-DD --max-live-turns 37 --llm-review --input-rub-per-1k 0.1 --output-rub-per-1k 0.2 --max-estimated-rub 120 --output eval/results/benchmark-new.json
python eval_runner.py --mode live --cases eval/completion_cases.json --visit-date YYYY-MM-DD --max-live-turns 8 --llm-review --input-rub-per-1k 0.1 --output-rub-per-1k 0.2 --max-estimated-rub 65 --output eval/results/regression-new.json
python eval_runner.py --mode live --cases eval/extended_cases.json --case L01 --visit-date YYYY-MM-DD --max-live-turns 15 --llm-review --input-rub-per-1k 0.1 --output-rub-per-1k 0.2 --max-estimated-rub 65 --output eval/results/long-new.json
python eval_runner.py --mode simulated --output eval/results/faults-new.json
```

Использовать новое имя отчёта: существующие результаты не перезаписываются. Параметр `--case` позволяет начать с одного сценария. Ограничитель расходов срабатывает между репликами, поэтому один ход может превысить остаток. Тариф Flash на 10.11.2026: 0,10 ₽ / 1000 входных и 0,20 ₽ / 1000 выходных токенов. В отчётах полной модели применялись 0,50/1,20 ₽ соответственно; смешивать эти ставки нельзя. Расход Maps и скидки за кэш не включены; это расчёт, не счёт провайдера.

В публичных JSON и CSV нет сырых ответов Maps. Для выборочной сверки можно использовать `--inspect` или `--spot-check CASE_ID`: данные показываются временно в терминале. Отчёт содержит вердикты и категории, а не копию выдачи.

## Предыдущие измерения

Ранние отчёты сохранены в `eval/results`, вместе с соответствующими тегами исходного кода. Они не суммируются с текущими показателями. Основной набор r10 на Flash дал 20/30 по всем критериям; повтор длинного диалога r12 получил 13/15 ответов. Это результаты других версий и другой модели. Промежуточные прогоны полной модели и отрицательные сверки также сохранены, включая неудачные первые попытки.

Автоматические тесты проверяют работу агента, память разговора, маршруты, источники, клиент Yandex и веб-интерфейс. Они используют тестовые ответы вместо внешних API. Запуск: `python -m pytest -q`.
