пользователем в чате. Это инженерная сверка, а не выставленная преподавателем оценка.

## Требуется ли законченный проект

По буквальному тексту на сдаче нужен законченный учебный MVP: работающая
интеллектуальная система с подключённой LLM, MCP, интерфейсом и хостингом,
Eval, README и интерактивной HTML-презентацией. Сдать нужно две ссылки:
публичный репозиторий с материалами и работающий сервис.

Признаки частичной оценки есть: 5 баллов даются за частичную/нестабильную
MCP-интеграцию, нестабильный деплой и неполную воспроизводимость. Это градации
оценки, а не явно выделенная промежуточная версия с меньшими требованиями.
Отдельных требований «к рубежному контролю сделать только часть» в тексте нет.
Название контроля само по себе не меняет состав сдачи. Полноценный учебный MVP
не требует промышленной инфраструктуры или всех задуманных дополнительных функций.

## Что считать уже проверенным

- Реальные MCP-поиски и диалог через Groq + Maps MCP выполнялись успешно;
  подробности и пределы измерений приведены в README и token-usage.md.
- Последний прогон технических тестов: 144 passed. Тесты используют искусственные
  данные и подмены, не доказывают качество пользовательских рекомендаций.
- Пользователь подтвердил включение Global ZDR; добавлен переход с Qwen на Groq
  openai/gpt-oss-120b. Это техническая поддержка; вопрос совместимости кэша
  с условиями Maps остаётся открытым, см. [model-migration.md](model-migration.md).
  Автоматической смены модели или тарифа нет.
- Наблюдались выдуманные детали, неподтверждённые часы, ошибки источников, сеть и квоты.
  Введены ограниченные проверки и продолжение после остановки, но полный Eval отсутствует.
- В пользовательском выводе есть вызовы lookup_weather; само наличие строки вызова
  не доказывает правильность погодного результата. Маршрут и погода как законченные
  пользовательские возможности требуют проверки перед заявлением на защите.
- Последняя живая проверка веб-адаптера выполнила публичный технический поиск:
  1 MCP-вызов, 2 обращения LLM, 4980 входных + 88 выходных токенов.
  Локальный Chrome показал настольный и мобильный интерфейсы; полный Eval отсутствует.
- При этой сверке внешние API не вызывались, новый прогон pytest не выполнялся.

## Решение по MCP

Пользователь зафиксировал: официальный Google Maps Grounding Lite MCP подходит,
собственный MCP-сервер не требуется. Собственная часть проекта — клиент,
агентный цикл, выбор/исполнение инструментов, интерфейс и проверки.
Сервер-прокладка исключён из плана; разработка и деплой не зависят от дополнительного
уточнения этого вопроса. Это решение по объёму проекта, а не выставленная оценка.

## Главные изменения по сравнению с прежним планом

1. Статус MCP обновлён: реальный поиск уже выполнен, но стабильность не доказана.
2. Требования сдачи переведены в проверяемые этапы и итоговый чек-лист.
3. Eval выделен в самостоятельный обязательный этап с методикой и анализом ошибок.
4. Первый деплой перенесён до основного Eval, чтобы раньше выявить сетевые ограничения.
5. Итоговый README должен содержать весь обязательный материал; docs его дополняют.
6. Предусмотрены отдельный репозиторий и живая демонстрация с интерактивным HTML.
