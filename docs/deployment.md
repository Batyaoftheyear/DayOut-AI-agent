# Развёртывание DayOut

Приложение: https://dayout-ai-agent.streamlit.app/.
Репозиторий: https://github.com/Batyaoftheyear/DayOut-AI-agent.

## Локально

После клонирования установить зависимости, создать `.env` из шаблона и заполнить пять параметров по [инструкции](yandex.md).

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m streamlit run app.py
```

Открыть `http://localhost:8501`. Терминалу необходим исходящий HTTPS-доступ к Google и Яндексу. Доступная локальная страница сама по себе не означает, что среда запуска разрешает внешние API.

## Streamlit Community Cloud

1. Create app → GitHub repository `Batyaoftheyear/DayOut-AI-agent`.
2. Branch `main`, Main file path **`app.py`**.
3. Python 3.11 или 3.14. Зависимости загружаются из `requirements.txt`.
4. В Advanced settings → Secrets задать значения из `.streamlit/secrets.toml.example`.
5. Deploy; дождаться установки зависимостей и загрузки интерфейса.

Локальные `.env` и `.streamlit/secrets.toml` в Git не добавляются. Приоритет настроек: переменные окружения → Secrets → `.env`. Для текущей конфигурации указать `YANDEX_MODEL = "aliceai-llm-flash"`. После изменения Secrets выполнить Reboot app и начать новый диалог.

При замене ключа Maps обновить `GOOGLE_MAPS_API_KEY` отдельно в локальном `.env` и в Secrets опубликованного приложения. Изменение `.env` не передаёт новый ключ в Streamlit Cloud. Для обычного ключа в Google Cloud должны быть подключены Billing и Maps Experience agent tools API; этот API также разрешается в ограничениях ключа. Успешный локальный запрос подтверждает доступ из локальной среды, но не настройки ключа на хостинге.

После обновления кода дождаться завершения развёртывания в Streamlit и начать новый диалог. Текущий релиз агента — **`2026-11-10-r32`**; версия указана в `agent.py`, измерения разных релизов разделены в Eval. Старый сеанс может содержать прежние условия и незавершённые вызовы; для проверки обновления использовать кнопку «Новый диалог». Если приложение продолжает показывать прежнее поведение, выполнить Reboot app. Ссылка на HTML-презентацию находится в README.

Неактивное бесплатное приложение может засыпать. Открыть его заранее и нажать кнопку пробуждения, если она появилась. При затянувшемся запуске владелец может открыть Manage app → logs и Reboot app. У учебного сервиса нет гарантии непрерывной доступности.

## Проверка после размещения

Начать новый диалог: «Найди красивые места для прогулки вдвоём на юге Москвы». Должен выполняться поиск без повторного вопроса о городе. Проверить ссылки и раздел «Детали запроса».

В новом диалоге запросить «Какая погода завтра в Москве?». Дата инструмента должна соответствовать завтрашнему дню по Москве. Затем можно проверить прямой пеший маршрут между двумя адресами.

## Диагностика

| Ошибка | Действие |
| --- | --- |
| `ModuleNotFoundError` | Установить зависимости в `.venv` и использовать его Python |
| Ошибка сети | Проверить исходящий HTTPS, прокси, TLS и среду запуска |
| HTTP 400 Maps | Проверить аргументы и схему конкретного MCP-инструмента |
| HTTP 429 Maps | Проверить квоту Google; это не баланс Яндекса |
| HTTP 401/403 Yandex | Проверить ключ, права и каталог |
| HTTP 402 Yandex | Проверить платёжный аккаунт |
| HTTP 429 Yandex | Подождать восстановления лимита Яндекса |
| `finish_reason=length` | Достигнут лимит токенов отдельной генерации |
| Подбор ещё не завершён | Получены кандидаты, но итоговый ответ не завершил проверку |

При сетевом сбое генерация модели повторяется не более одного раза; результаты MCP при этом не запрашиваются повторно. Если первый запрос был принят, но ответ потерялся, его расход может остаться неизвестным. HTTP-ошибки, включая 429, автоматически не повторяются. Многократное нажатие повтора не увеличивает квоту.

## Обновления

Изменения в `main` публикуются в том же приложении; URL сохраняется. HTML-презентацию размещает GitHub Pages из корня `main`. Её адрес: https://batyaoftheyear.github.io/DayOut-AI-agent/presentation.html.

Технические проверки запускаются в GitHub Actions для Python 3.11 и 3.14. Они не вызывают внешние API и не заменяют живой Eval.
