# Запуск и развёртывание DayOut

Сервис: https://dayout-ai-agent.streamlit.app/.
Репозиторий: https://github.com/Batyaoftheyear/DayOut-AI-agent.
Entry point — **`app.py`**, ветка `main`. URL не меняется при обычных обновлениях кода.

## Локально

После клонирования из [README](../README.md):

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
Copy-Item .env.example .env
```

Заполнить `.env` и сохранить файл. `GOOGLE_MAPS_API_KEY` нужен именно в `.env`, не только в шаблоне. Ключи нельзя коммитить.

```powershell
.\.venv\Scripts\python.exe -m streamlit run app.py
```

Открыть localhost:8501. Запускать из терминала с исходящим HTTPS-доступом к Google и Яндексу: песочница IDE может разрешать страницу и блокировать API. Смена текста запроса такую сетевую блокировку не исправит.

## Streamlit Community Cloud

1. Create app → GitHub repository `Batyaoftheyear/DayOut-AI-agent`.
2. Branch `main`, Main file path **`app.py`**, не `streamlit_app.py`.
3. Выбрать доступный Python 3.11 или 3.14; оба проверяются в CI. Зависимости берутся из `requirements.txt`.
4. Advanced settings → Secrets, вставить свои значения:

```toml
LLM_PROVIDER = "yandex"
YANDEX_API_KEY = "your-yandex-key"
YANDEX_FOLDER_ID = "your-folder-id"
YANDEX_MODEL = "aliceai-llm-flash"
GOOGLE_MAPS_API_KEY = "your-maps-key"
```

5. Deploy. После изменения Secrets выполнить Reboot app и начать новый диалог.
6. Проверить загруженную версию в «О проекте»: **`2026-10-30-r6`**. Наличие нового коммита на GitHub само по себе не доказывает, что старый процесс уже перезапущен.

Локальный `.env` не меняет облачные Secrets. Приоритет: окружение процесса → Secrets → `.env`. При `LLM_PROVIDER=yandex` значения Groq не используются; автоматического переключения нет.

Ключи хранятся на стороне сервера, в браузер не передаются. В репозиторий входят `.env.example` и `.streamlit/secrets.toml.example` с пустыми/учебными значениями.

## Проверка доступности

Неактивное бесплатное приложение может заснуть. На странице сна нажать «Yes, get this app back up!» и дождаться загрузки. Перед демонстрацией открыть сервис заранее. Если запуск затянулся, владелец может посмотреть Manage app → logs и Reboot app. В CI проверяется код, а не постоянная доступность хостинга.

Проверить новый диалог с кратким запросом, например «Подбери два музея Москвы об истории города». Посмотреть инструменты и исходные ссылки. Старая история после обновления не является проверкой чистой версии.

## Что означают ошибки

| Сообщение | Что проверить |
| --- | --- |
| Нет `dotenv`/`streamlit` | Запущен ли Python из `.venv`, установлены ли зависимости |
| Ошибка сети MCP | Исходящий HTTPS, прокси/TLS, среду запуска; не только ключ |
| Google Maps HTTP 400 | Схему, аргументы и этап MCP. Общий статус не раскрывает конкретную причину |
| Google Maps HTTP 429 | Квоты Google. 30.10 подтверждён дневной лимит Demo Key; Яндекс-баланс его не меняет |
| Yandex HTTP 429 | Лимиты именно Яндекса; это отдельный сервис |
| Yandex HTTP 401/403 | Ключ, права и каталог |
| `finish_reason=length` | Потолок токенов отдельной генерации, не доказательство пустого баланса |
| `content_filter` | Фильтр провайдера, не сетевой сбой |
| Подбор ещё не завершён | Есть только кандидаты; итоговый ответ не прошёл/не завершил проверку |

При отказе не нажимать повтор много раз: это не увеличивает квоту и может расходовать LLM-токены. Для Demo Key Google описывает возобновление после дневного сброса, точное время из текущего ответа не установлено. [Документация Google](https://developers.google.com/maps/demo-key).

## Проверки и расходы

`pytest` — без API. `yandex_check.py` выполняет платные небольшие генерации. `mcp_check.py` вызывает настоящий Maps, расходуя его квоту. Live Eval платный и использует оба сервиса; [методика и команды](evaluation.md).

У приложения нет SLA и защиты бюджета уровня биллинга. Для учебной публичной ссылки используйте отдельные ключи и контролируйте расход в кабинетах провайдеров. Постоянная нагрузка требует подходящего Maps-ключа, лимитов и более надёжного хостинга.
