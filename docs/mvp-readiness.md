## Граница защищаемого MVP

Досуг в Москве, диалог и уточнения, поиск, погода, пеший маршрут, источники. Сумма сохраняется как ограничение; цена подтверждается только данными. За границей: бронирование, оплата, точный чек, постоянный профиль, своя база и свой MCP-сервер.

## Проверка перед защитой

1. Открыть сайт заранее, дождаться пробуждения. В «О проекте» проверить `2026-10-30-r6`, начать новый диалог.
2. Убедиться в доступности Яндекса и Maps. Maps HTTP 429 не исправляется пополнением Яндекса.
3. Пройти короткое демо из [defense.md](defense.md), не из старого диалога.
4. Открыть `presentation.html` локально; проверить навигацию, сохранить PDF как запасной вариант.
5. После восстановления квоты продолжить 51 ещё не начатую попытку, обновить сводку и слайды. Новые исправления runtime измерять отдельно.

Сейчас оформлен пакет материалов с честным частичным результатом. Объявлять все сценарии исправленными и окончательную стабильность подтверждённой оснований нет.
