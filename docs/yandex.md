# Подключение Yandex AI Studio

Текущая конфигурация: `LLM_PROVIDER=yandex`, Alice AI LLM Flash через
`https://ai.api.cloud.yandex.net/v1/chat/completions`. Модель выбирается явно;
поддержка Яндекса не активирует Groq в качестве автоматического резерва.

## Локально

Добавьте в существующий `.env`, сохранив ключ Maps:

```dotenv
LLM_PROVIDER=yandex
YANDEX_API_KEY=your-yandex-api-key
YANDEX_FOLDER_ID=your-folder-id
YANDEX_MODEL=aliceai-llm-flash
```

Идентификатор каталога можно взять из URL консоли:
`https://console.yandex.cloud/folders/<folder-id>`. Не используйте имя `default`
или ID платёжного аккаунта. Ключ должен иметь доступ к генерации в этом каталоге.
Короткое имя приводится к `gpt://<folder-id>/aliceai-llm-flash/latest`:
именно этот URI вернул реальный Models API при проверке 27 октября 2026 года.

```powershell
.\.venv\Scripts\python.exe yandex_check.py
.\.venv\Scripts\python.exe dayout.py --usage
.\.venv\Scripts\python.exe -m streamlit run app.py
```

`yandex_check.py` делает GET списка моделей и три небольших генерации: проверку
связи и искусственный цикл tool calling. Это платные вызовы модели, не офлайн-тест.
Google Maps в этой проверке не вызывается. Обычный pytest использует подмены
API и не расходует платные токены.

## Существующий сайт

После обновления кода в GitHub откройте Streamlit Cloud → Settings → Secrets:

```toml
LLM_PROVIDER = "yandex"
YANDEX_API_KEY = "your-yandex-api-key"
YANDEX_FOLDER_ID = "your-folder-id"
YANDEX_MODEL = "aliceai-llm-flash"
GOOGLE_MAPS_API_KEY = "your-existing-google-maps-api-key"
```

Локальный `.env` не загружается на хостинг. Перезапустите приложение и начните
новый диалог. URL сайта и репозитория сохраняются. Приоритет конфигурации:
переменные окружения процесса → Secrets → локальный `.env`. Без `LLM_PROVIDER`
сохраняется прежний режим Groq для совместимости со старым деплоем.

## Что изменилось

Адаптер отправляет `Authorization: Bearer`, `OpenAI-Project` и
`x-data-logging-enabled: false`. Используется stateless Chat Completions;
Groq-only параметры reasoning не передаются. Часы ожидания токенового окна Groq
не применяются к Яндексу. Реальный HTTP 429 и числовой Retry-After по-прежнему
сохраняют ход для ручного продолжения; автоматических повторов нет.

Проверки схем инструментов, источников, лимит 8 попыток вызова MCP, таймаут,
раздельные браузерные истории и общий ограничитель процесса сохранены. Сайт
по-прежнему допускает один запрос одновременно и минимум 5 с между началами
действий. Ключи не помещаются в браузерную историю или логи.

Отключение логирования запросов не является универсальным ZDR: оно отдельно
от трейсинга, ресурсов Responses/Conversations и кэширования провайдера. Здесь
эти сохраняющие историю API не используются; трейсы не включаются. Полная
совместимость обработки данных провайдером с условиями Maps не подтверждена.

## Проверенные результаты и расходы

27.10.2026 искусственный цикл прошёл: 3 генерации, 307 входных и 38 выходных
токенов. По опубликованной цене Flash 0,10 ₽/1000 входных и 0,20 ₽/1000 выходных
это около 0,038 ₽ до учёта гранта/скидок. Это расчёт по usage, не выписка биллинга.

Двухходовый CLI smoke-тест с реальным MCP также прошёл: поиск кафе, затем
уточнение без нового поиска. 3 обращения LLM, 5676 входных + 102 выходных токена;
первый ход 5,4 с, второй 1,2 с, оценка стоимости 0,588 ₽. Поиск дал один
подтверждённый вариант вместо запрошенных двух: это ограничение результата,
а не доказательство прохождения Eval качества. Данные мест в файлы не включены.

Отдельный живой smoke-тест веб-адаптера дал две рекомендации с непосредственными
ссылками: один MCP-поиск, две генерации, 3975 входных и 93 выходных токена,
5,4 с, оценка 0,416 ₽. Все три короткие проверки вместе: 8 генераций,
9958 входных + 233 выходных токена, оценка 1,042 ₽. Публичный хостинг после
изменения Secrets нужно проверить отдельно.

В подготовленной копии публичного репозитория прошли все 180 технических тестов.
Проверены настройки и скрытие ключей, параметры и заголовки Яндекса, protocol
tool calling, учёт usage, отсутствие переноса квот Groq и обработка HTTP-ошибок
без автоматических повторов. Это проверки реализации, не Eval рекомендаций.

Большой Eval при миграции не запускался. Погода, MCP HTTP 400 и нерелевантные
источники старой истории остаются отдельными задачами диагностики.
