# Демонстрация DayOut

Перед демонстрацией открыть приложение и начать новый диалог. Для обращения к модели и Maps необходим доступ к обоим сервисам; презентация работает локально без API.

Пример короткой демонстрации:

1. «Подбери два музея Москвы для человека, которому интересна история города».
2. «Выбери один из найденных, используя только полученные данные».
3. «Какая погода в Москве завтра? Нужен прогноз на день».

В ответе показать источники, затем раскрыть детали запроса: инструменты, время и токены. Для дополнительного примера маршрута: «Построй пеший маршрут от Красной площади до Волхонки, 12, Москва».

Управление HTML-презентацией: стрелки — переходы, Home/End — начало и конец, F — полный экран, N — заметки. PDF служит вариантом для просмотра без браузерных взаимодействий.

Материалы: [приложение](https://dayout-ai-agent.streamlit.app/), [репозиторий](https://github.com/Batyaoftheyear/DayOut-AI-agent), [HTML](../presentation.html), [PDF](DayOut-presentation.pdf).

При отказе API сообщение об ошибке показывается как фактический результат. Сохранённые метрики Eval характеризуют указанные версии и не заменяют живую доступность сервиса.
