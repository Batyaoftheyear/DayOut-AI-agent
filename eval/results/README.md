# Индекс результатов Eval

Все файлы содержат метрики и категории, без сырых ответов Maps. Версии runtime различаются: их нельзя смешивать в одну оценку качества.

Разметка в `.review.csv` экспортирована из LLM-review, это не независимый человеческий аудит. Исходные неуспехи сохраняются. Дальнейшее продолжение должно иметь новое имя и родительский SHA. Сводки и отчёты продолжения включают родительские расходы: не суммировать их повторно.

## Разработка 30.10, до заморозки

`preflight`, `development-r4`, `diagnostics-r4`, `corrections-r5`, `extended-r5`: реальные пилоты, которые помогли обнаружить дефекты протокола, географии и диалога. Они включены только в расчёт сегодняшних затрат, не в итоговую метрику r6.

## Архив 27–29.10

`live-pilot`, `cloud-smoke`, `simulated`, `offline`, `offline-current`, файлы `pilot-*` — разработческие проверки прежних версий. Название `pilot-final` не означает окончательную оценку. В ранних отчётах пустой объект ошибочно классифицировался как tool_error; последующая диагностика установила успешную пустую выдачу. Старые записи не переписаны.

Отдельные диагностические вызовы прошлых дат не входят в сегодняшний расчёт. Все расходы сверять с биллингом, usage не является выпиской.
