# Результаты Eval

Отчёты о проверке DayOut с Alice AI LLM Flash. Дата, версия кода, параметры запуска и модель записаны в metadata каждого измерения.

| Отчёт | Содержание |
| --- | --- |
| [Основной набор · 02.11.2026](release-r10-2026-11-02.json) | 30 сценариев: поиск мест, диалог, погода, маршруты и Place ID |
| [Длинный диалог · 02.11.2026](long-dialogue-repeat-r12-2026-11-02.json) | 15 запланированных сообщений в одном разговоре |
| [Презентация и PDF](presentation-release-2026-11-10.json) | Навигация, мобильное отображение и экспорт 10 страниц |

Результаты разных запусков не объединяются в одну оценку. Неудачные попытки включены в показатели. Сырые ответы Maps не сохраняются. Поле `manual_scores` в прежнем формате может содержать модельную оценку; способ проверки указан в metadata.review_method.
