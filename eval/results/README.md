# Разработческие проверки 29 октября 2026

Это подготовка Eval, не финальная оценка качества. Все отчёты содержат только
метаданные и числовые наблюдения; ответы и содержимое Maps не сохранены.
Файлы разных версий имеют разные `code_sha256`; их нельзя объединять в одну
оценку одной модели/версии приложения. Ни один из этих запусков не использовал holdout.

| Отчёт | Что проверялось / обнаружено |
| --- | --- |
| offline-2026-10-29.json | Четыре искусственных сценария, без внешних запросов |
| offline-current-2026-10-29.json | Те же четыре сценария на текущем коде, без внешних запросов |
| pilot-quality-2026-10-29.json | Две попытки остановились на формате плана |
| pilot-quality-format-fix-2026-10-29.json | Найдены несовместимость свободного JSON-плана и неверная трактовка пустой выдачи |
| pilot-quality-structured-2026-10-29.json | Погода завершена, поиск блокировался пустым объектом |
| pilot-category-budget-2026-10-29.json | Оба хода завершились пустой выдачей; категория и сумма сохранены |
| pilot-final-2026-10-29.json | Найдены лишний барьер уточнения цены и отказ погоды с languageCode |
| pilot-mvp-2026-10-29.json | Завершены кафе → бани и погода; качество ещё не размечено |

Названия файлов описывают момент разработки. В частности, слово `final` в имени
раннего пилота не означает итоговый Eval или актуальную версию кода.
После последнего пилота исправлены противоречивая формулировка бюджета и сохранение
фактических аргументов для временного просмотра. Новый платный прогон не выполнялся.

Старые отчёты сохраняют тогдашнюю классификацию runner: в некоторых из них пустой
объект ошибочно записан как `tool_error`, хотя последующая проверка установила
успешный пустой ответ. Эти записи не переписывались задним числом.

Отдельные диагностические обращения к LLM на искусственных условиях не входят
в usage сценарных отчётов. Сумма usage этих файлов не является полным счётом за
разработку; стоимость и баланс нужно сверять с кабинетом провайдера.
