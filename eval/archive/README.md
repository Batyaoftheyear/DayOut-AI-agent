# Архив измерений

Здесь сохранены прогоны прежних версий приложения. Дата в имени файла и SHA-256 кода позволяют определить измеренную реализацию. Результаты разных версий нельзя объединять в одну оценку качества.

Актуальный релиз и его первичные материалы описаны в [методике Eval](../../docs/evaluation.md). Архивные показатели не включаются в его итоговую таблицу.

Файлы содержат метрики и категории ошибок без сырых ответов Google Maps. Названия ранних файлов с `pilot`/`final` отражают разработческие этапы, а не статус текущего релиза.
